WHAT THIS IS
------------
Text-only repo for MUSC 1105 Fall 2026 homework assignments that span
more than one app, or an app and no app. See conversation_starter.txt
for the why. No code, no build, no tests — the verification standard
here is "every path a file names exists, every course id / rubric /
title it quotes matches the owning repo exactly, and the roster row
agrees with the content file".

CONVENTIONS
-----------
  - Five-section shape for every hw file (see conversation_starter).
  - Section 1's description is REAL HTML (Canvas's description field is
    rich content; bare newlines collapse). Between ===HTML=== fences so
    the paste boundary is unambiguous. Grading_Hub's tab 5 passes HTML
    through untouched when it sees a tag (AssignmentSpec.html_from_plain).
  - [FILL IN] marks a decision only Sam can make (a due date). Never
    resolve one silently; list it in section 5.
  - Absolute dates everywhere. Plain .txt, never .md.
  - AMERICAN SPELLING, always (Sam, 2026-09-20): favor, color, gray,
    center, practice (the verb too), recognize. Never favour / practise /
    colour. Grep a file for -our / -ise / -re words before calling it
    ready to paste; the coursepack's build enforces the same list.
  - Never put student names, ids or grades in this repo (FERPA) — sheets
    and CSVs live in ~/Documents/MUSC1105_Grades/.
