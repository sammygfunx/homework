WHAT THIS IS
------------
The home for MUSC 1105 (Fall 2026) homework assignments that do NOT
belong to one single app. Every —Games/ and —Apps/ project keeps its own
canvas_assignment_*.txt when an assignment IS that app (Da Capo's Steps
and Skips, Diatonic Triad Dodge's HW #9). An assignment that spans "no
app at all" and one game — or two apps, or a paper option beside an app
option — has no natural owner, and before 2026-09-15 would have been
parked in whichever repo was nearest. This folder is where those live.

It is text only: no Godot project, no build, no deploy. It holds
  hw<N>_<slug>.txt      one ready-to-paste assignment per file, in the
                        same five-section shape every canvas_assignment_
                        *.txt in the OER already uses (1 title + HTML
                        description, 2 the ninety-second in-class
                        version, 3 the message to students, 4 Sam's
                        Grading_Hub click-path, 5 thread notes + open
                        questions — never for students)
  docs/roster.txt       ONE running table of every "HW #N" of the
                        semester: title, apps + submission types, due
                        date, rubric path in Grading_Hub, content file,
                        status (drafted / created in Canvas / live /
                        graded). Update it whenever a row's status
                        changes, in any pass, in any repo.
  the four docs         this file, project_state.txt, next_steps.txt,
                        history.txt

HOW IT RELATES TO THE REST OF THE OER
-------------------------------------
  - GRADING_HUB (—Apps/Grading_Hub) owns every rubric (rubrics/*.rubric.
    json), CREATES the Canvas assignments (tab 5), pulls + grades KTS1
    codes (tabs 1/3/4) and posts hand-graded sheets (tab 6). Nothing in
    this folder is a rubric; every row of docs/roster.txt points at the
    rubric's path there. The hub BUILDS rubrics and CREATES assignments
    in its own UI — that is Sam's click-path (each hw file's section
    4), not something to hand-write here.
  - THE GAMES/APPS own their course ids and their own single-app
    assignment files. A COURSE ID IS A PUBLIC IDENTIFIER once a rubric
    names it (Da Capo's "steps", "fourths") — a file here may quote it
    but never decides it.
  - —OER/docs is the program-level roadmap; a pass that touches this
    folder gets a line in —OER/docs/project_state.txt's pass writeups
    like any other repo.
  - Canvas assignment TITLES are the hub's idempotent re-run match key.
    Once created, the title in a hw file's section 1 must not change.
